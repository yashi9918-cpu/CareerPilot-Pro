# CareerPilot Pro

CareerPilot Pro is a C++ Object-Oriented Student Career Management System developed using OOP concepts and File Handling.

## Features

- Student Registration
- View Students
- Search Student
- Update Student
- Delete Student
- Skills Management
- Resume Upload
- Certificate Upload
- Internship Documents
- Project Management
- Career Recommendation
- Career Readiness Score
- Save Student Data

## Technologies

- C++
- Object Oriented Programming
- File Handling
- STL (Vector)
- Visual Studio Code
- MSYS2 MinGW GCC

## OOP Concepts Used

- Classes
- Objects
- Inheritance
- Encapsulation
- Abstraction
- Modular Programming
